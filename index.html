Battle Realms Lookup & Comparison Tool

Unit Counter Lookup & 1v1 Comparison (Zen Edition)

📖 How to Use Counter Lookup:
• Target Selection: Select a target unit to inspect its armor multipliers and damage types. Counter units are grouped into Tier 1, 2, and 3 tabs by effectiveness. Click each available tab to view the full unit list.
• Safe & Dominant Counters (Tier 1): Deals high damage (≥125%) to the target while taking equal or lower in return (Deals ≥ Takes).
• Effective Counters (Tier 2): Deals standard damage (100%) to the target while taking equal or lower in return.
• High-Risk Counters (Tier 3): Deals effective damage (≥100%) to the target while taking heavier damage in return (Deals < Takes).
📖 How to Use Resistance Filter:
• Resistance Category: Choose between Weak Resistance (units taking ≥ 100% damage, sorted high → low) or Strong Resistance (units taking < 100% damage, sorted low → high).
• Damage & Unit Type: Select an attack damage type and filter by melee or missile units.
• Custom Sort: Click the sort button anytime to reverse the order.
📖 How to Use 1v1 Comparison:
• Unit Selection: Select Unit A and Unit B to start comparing.
• Two-Way Comparison: Compares the damage effectiveness of A against B and vice versa based on both units' resistances and damage types (including skills, if available).
• Verdict: Evaluates which side holds the armor advantage (better resistance against the opponent's damage). This reflects defensive efficiency rather than the actual outcome of a 1v1 duel.
📖 How to Use Database Changes:
• Load files: Choose the OLD and the NEW game database (.xlsx), then click Compare. Every sheet is compared. The optional rules file adds readable names next to numeric codes and marks player-relevant sheets.
• Matching: Rows are matched by their first column (usually Type); Enum_* sheets are matched by Description. Differences are cell value changes, added / removed rows, added / removed columns and added / removed sheets.
• Filters: Use the Quick Filters bar to narrow the list by sheet, change type, field, keyword, numeric change size or direction. Click a summary chip or a sheet row to filter instantly. Results can be exported to CSV.
